# Bus Pass Management System

## Project Overview

The Bus Pass Management System is a web-based application developed using PHP and MySQL. It helps manage bus pass applications, approvals, renewals, and records efficiently through an online platform.

## Features

* User Registration and Login
* Apply for New Bus Pass
* View Pass Details
* Download Bus Pass
* Admin Dashboard
* Manage Categories
* Manage Pass Records
* Search Pass Records
* Generate Reports
* Contact and Enquiry Management

## Technologies Used

* PHP
* MySQL
* HTML
* CSS
* JavaScript
* Bootstrap

## Software Requirements

* XAMPP/WAMP Server
* PHP 7.x or later
* MySQL Database
* Web Browser

## Installation Steps

1. Download or clone the repository.
2. Install XAMPP or WAMP.
3. Copy the project folder into the `htdocs` directory.
4. Start Apache and MySQL services.
5. Open phpMyAdmin.
6. Create a database named `buspassdb`.
7. Import the SQL file located in:
   `SQL File/buspassdb.sql`
8. Open your browser and visit:
   `http://localhost/buspassms`

## Admin Login

Use the credentials configured in the database or project files.
